# MG Studio

MGSOFT의 Windows용 화면 녹화 · 영상 편집 프로그램입니다.

## 내려받기

[최신 버전 내려받기](https://github.com/mgsoftworks/MGStudio-releases/releases/latest) — `MG.Studio.Setup.<버전>.exe`를 실행하세요.

- Windows 10 · 11 (64비트)
- 설치한 뒤에는 앱 안의 도움말(?) → 업데이트로 새 버전을 받을 수 있습니다.
- 설치 파일에 아직 코드 서명이 없어 처음 실행할 때 Windows가 경고를 보일 수 있습니다. "추가 정보 → 실행"을 누르면 설치됩니다.
